# 📖 Overview

**HTML to APK Converter v4.3** is a Python-powered automation tool that transforms complete web projects into native Android applications.

Instead of manually creating an Android Studio project, configuring WebView, copying assets, generating launcher icons, editing the Android Manifest, and building the APK, this application automates the entire workflow.

Whether you're a **Web Developer**, **Student**, **Freelancer**, or **Business Owner**, you can package your website into an Android application quickly and efficiently.

# 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/A-Santhosh-Hub/HTML_to_APK_Converter-Using-Python-.git
```

Go to the project directory:

```bash
cd HTML_to_APK_Converter-Using-Python-
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python converter.py
```

Or launch the Web UI if included in your project.

# 🖥 How to Use

1. Upload your website ZIP.
2. Upload an application icon.
3. Enter:

   * App Name
   * Package Name
   * Version
4. Click **Build APK**.
5. Wait for the build to complete.
6. Download the generated APK.
